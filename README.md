# Rajxd — Personal Portfolio

Personal portfolio of Raj Mahesh Metry, first-year B.Tech Artificial Intelligence student at NIAT, Pune.

## Live website

https://rajmetry.github.io/Portfolio/

## Source repository

https://github.com/RajMetry/Portfolio

## What's inside

- Responsive HTML5 and CSS3 portfolio
- Home, About, Skills, Projects, and Contact sections
- LEFT EYE project showcase
- Yepp / First Contributions open-source fork showcase
- Contact form with required-field validation

## Projects

- [LEFT EYE](https://github.com/RajMetry/left-eye-homunculus) — local-first interactive 3D body-metaphor visualizer. A creative prototype, not a diagnostic tool.
- [Yepp](https://github.com/RajMetry/Yepp) — my fork of [First Contributions](https://github.com/firstcontributions/first-contributions), a beginner-friendly open-source contribution guide.

## Built with

HTML5 and CSS3 is used in this portfolio website.

## Run locally

Open `index.html` in a browser. Keep `style.css` and the `images` folder alongside it.
